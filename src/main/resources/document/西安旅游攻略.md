# 西安旅游攻略

## 景点推荐

### 兵马俑
- **地址：** 西安市临潼区秦陵北路
- **开放时间：** 8:30-17:30
- **门票：** 120元
- **建议游玩时间：** 2-3小时
- **交通：** 西安火车站乘游5(306)路直达
- **小贴士：** 建议请讲解员或租讲解器，不然就是看泥人。1号坑最大最震撼，2号坑有精品陈列。

### 大雁塔
- **地址：** 西安市雁塔区慈恩路1号
- **开放时间：** 8:00-17:30
- **门票：** 登塔25元，大慈恩寺40元
- **建议游玩时间：** 1-2小时
- **小贴士：** 晚上有音乐喷泉表演（免费），非常壮观

### 西安城墙
- **地址：** 西安市碑林区
- **开放时间：** 8:00-22:00
- **门票：** 54元
- **建议游玩时间：** 2-3小时
- **特色：** 可租自行车骑行（45元/辆），全程约14公里
- **推荐时间：** 下午5点上城墙，骑到日落

### 陕西历史博物馆
- **地址：** 西安市雁塔区小寨东路91号
- **开放时间：** 9:00-17:30（周一闭馆）
- **门票：** 免费需预约
- **建议游玩时间：** 2-3小时
- **小贴士：** 提前3天在公众号预约，非常难抢

### 回民街
- **地址：** 西安市莲湖区
- **特色：** 西安最著名美食街
- **建议游玩时间：** 1-2小时
- **美食推荐：** 肉夹馍、羊肉泡馍、凉皮、biangbiang面、灌汤包

## 美食推荐
- **肉夹馍：** 子午路张记、秦豫肉夹馍
- **羊肉泡馍：** 老孙家、同盛祥
- **凉皮：** 魏家凉皮
- **特色饮品：** 冰峰汽水、酸梅汤

## 住宿建议
- **经济型：** 300-400元/晚
- **舒适型：** 400-700元/晚
- **推荐区域：** 钟楼/鼓楼附近，交通便利

## 交通指南
- 西安地铁覆盖主要景点，支付宝可直接刷码
- 市内景点打车一般10-30元

## 三日游推荐行程

### Day 1 - 东线一日
- 上午：兵马俑（建议8:30开门即入）
- 下午：华清宫
- 晚上：回市区，去永兴坊吃小吃

### Day 2 - 市区人文
- 上午：陕西历史博物馆
- 下午：大雁塔 + 大唐不夜城
- 晚上：大唐不夜城夜景

### Day 3 - 古城体验
- 上午：西安城墙骑行
- 下午：钟楼/鼓楼 + 回民街
- 傍晚：返程
