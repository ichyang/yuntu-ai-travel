# 北京旅游攻略

## 景点推荐

### 故宫博物院
- **地址：** 北京市东城区景山前街4号
- **开放时间：** 8:30-17:00（周一闭馆）
- **门票：** 旺季60元，淡季40元
- **建议游玩时间：** 3-4小时
- **推荐季节：** 春秋两季最佳
- **小贴士：** 建议提前7天在官网预约，旺季一票难求。可以从午门进，神武门出，出来后直接去景山公园看全景。

### 八达岭长城
- **地址：** 北京市延庆区G6京藏高速58号出口
- **开放时间：** 7:30-17:30
- **门票：** 旺季40元，淡季35元
- **建议游玩时间：** 半天
- **交通：** 德胜门乘877路直达，或S2线城际列车
- **小贴士：** 建议早上去，人少光线好。穿舒适的运动鞋，部分坡道较陡。

### 颐和园
- **地址：** 北京市海淀区新建宫门路19号
- **开放时间：** 6:30-18:00
- **门票：** 旺季30元，联票60元
- **建议游玩时间：** 2-3小时
- **推荐季节：** 春季赏花，夏季避暑

### 天坛公园
- **地址：** 北京市东城区天坛内东里7号
- **开放时间：** 6:00-21:00
- **门票：** 旺季15元，联票34元
- **建议游玩时间：** 1-2小时

### 南锣鼓巷
- **地址：** 北京市东城区
- **特色：** 老北京胡同文化
- **建议游玩时间：** 1-2小时
- **美食推荐：** 炸酱面、豆汁儿、焦圈、卤煮

## 美食推荐
- **北京烤鸭：** 全聚德、大董、便宜坊
- **涮羊肉：** 东来顺、聚宝源
- **炸酱面：** 海碗居、方砖厂69号
- **小吃街：** 王府井小吃街、牛街、护国寺小吃

## 住宿建议
- **经济型：** 如家、汉庭（300-500元/晚）
- **舒适型：** 全季、亚朵（500-800元/晚）
- **豪华型：** 王府井希尔顿、中国大饭店（1000+/晚）
- **推荐区域：** 东城区/西城区，近地铁站

## 交通指南
- 下载「北京一卡通」或使用支付宝刷码乘车
- 地铁覆盖主要景点，建议住在地铁站附近
- 高峰期（7:00-9:00，17:00-19:00）尽量避开地铁

## 三日游推荐行程

### Day 1 - 经典中轴线
- 上午：天安门广场 → 故宫博物院
- 下午：景山公园 → 北海公园
- 晚上：南锣鼓巷 + 什刹海

### Day 2 - 皇家园林
- 上午：颐和园
- 下午：圆明园
- 晚上：鸟巢/水立方（外观）

### Day 3 - 长城一日游
- 全天：八达岭长城
- 傍晚回市区：王府井逛街
