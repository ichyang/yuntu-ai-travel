# 成都旅游攻略

## 景点推荐

### 大熊猫繁育研究基地
- **地址：** 成都市成华区熊猫大道1375号
- **开放时间：** 7:30-18:00
- **门票：** 55元
- **建议游玩时间：** 3-4小时
- **小贴士：** **一定要早上去！** 熊猫在上午最活跃，9点以后就睡觉了。建议7:30开门就冲进去看月亮产房。

### 宽窄巷子
- **地址：** 成都市青羊区长顺街
- **开放时间：** 全天
- **门票：** 免费
- **建议游玩时间：** 1-2小时
- **特色：** 由宽巷子、窄巷子、井巷子组成，体验成都慢生活

### 锦里古街
- **地址：** 成都市武侯区武侯祠大街231号
- **开放时间：** 全天
- **门票：** 免费
- **建议游玩时间：** 1-2小时
- **特色：** 紧邻武侯祠，夜景很美

### 武侯祠
- **地址：** 成都市武侯区武侯祠大街231号
- **开放时间：** 9:00-18:00
- **门票：** 50元
- **建议游玩时间：** 1-2小时
- **特色：** 三国文化爱好者必去

### 青城山
- **地址：** 成都市都江堰市
- **开放时间：** 8:00-17:30
- **门票：** 前山90元，后山20元
- **建议游玩时间：** 半天到一天
- **特色：** "青城天下幽"，道教名山

### 都江堰
- **地址：** 成都市都江堰市
- **开放时间：** 8:00-17:30
- **门票：** 80元
- **建议游玩时间：** 2-3小时
- **特色：** 世界水利工程奇迹

## 美食推荐
- **火锅：** 小龙坎、大龙燚、蜀大侠
- **串串香：** 钢管厂五区小郡肝
- **川菜：** 陈麻婆豆腐、夫妻肺片
- **小吃：** 担担面、龙抄手、钟水饺、三大炮、兔头
- **喝茶：** 人民公园鹤鸣茶社，体验成都盖碗茶文化

## 住宿建议
- **推荐区域：** 春熙路/太古里附近或宽窄巷子附近
- **经济型：** 300-400元/晚
- **舒适型：** 400-600元/晚

## 交通指南
- 成都地铁覆盖主要景点，使用天府通APP
- 去熊猫基地可乘地铁3号线到熊猫大道站转接驳车

## 四日游推荐行程

### Day 1 - 市区初体验
- 上午：大熊猫基地
- 下午：宽窄巷子
- 晚上：锦里 + 武侯祠

### Day 2 - 自然风光
- 全天：青城山或都江堰
- 晚上：回市区吃火锅

### Day 3 - 人文美食
- 上午：人民公园（鹤鸣茶社喝茶）
- 下午：文殊院 + 太古里
- 晚上：九眼桥酒吧街

### Day 4 - 自由安排
- 上午：三星堆博物馆（广汉，高铁20分钟）
- 下午：购物 + 返程
